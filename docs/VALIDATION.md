# Software validation and evidence limits

This public preview supports Python 3.12 only. Its final artifact qualification is recorded with the immutable release. Other interpreter versions are outside this preview's support statement.

The Novum source baseline passed 111 tests on each Python 3.9–3.14 and 13 canonical program output comparisons. An earlier bounded candidate passed fresh installation checks on Python 3.9–3.14 and five positive plus six controlled-negative DSC exchanges on Python 3.11–3.14. The subsequent attribution revision kept the stable source code and `novum-dsc/0.1` contract byte identical, built twice into identical artifacts, and passed Python 3.12.14 installation and exchange checks. This bounded package changes release-facing metadata and prose, retaining the stable source bytes.

See the versioned release record for exact public archive and wheel hashes, build environment, and final installation and exchange qualification. The tests establish bounded parsing, validation, graph behavior, diagnostics, export, and contract-bounded exchange for tested builds. They do not establish invention efficacy, solution quality, novelty, a transformation advantage, or generalization. Preservation across `novum-dsc/0.1` is not full semantic equivalence.
